# 軍師チェス (ai-chess)

自分で普通に指してもいいし、組み込みの古典的 AI が「性格」ごとに提示する複数の良手から
軍師気分で選ぶだけでもかなり戦える、ブラウザで動くチェスゲームです。

依存ライブラリなし・ビルド不要。`index.html` を開くだけで遊べます。

## 遊び方

```sh
# そのまま index.html をブラウザで開く、または
npm start      # http://localhost:8080
```

- 盤面の駒をクリック → 移動先をクリックで自分で指せます。
- 右側の「軍師の進言」カードをクリックすると、その手を指します。
- カードにマウスを乗せると盤上の矢印が強調されます。
- 「待った」で 1 手戻せます。

## 軍師たち

各軍師は同じ探索エンジンを使いつつ、評価関数の重みが違います。
まず総合評価 (参謀) で全候補手を採点し、そこから大きく劣らない手の中で、
各性格の評価で最良の手を選びます。**性格は出るが大悪手は出ない**仕組みです。

| 軍師 | 性格 | 重視するもの |
| --- | --- | --- |
| 📐 参謀 | 均衡型 | 総合評価の最善手 |
| 🔥 猛将 | 攻撃型 | 敵王への圧力、駒の活動力。多少の損は気にしない |
| 🛡️ 守将 | 防御型 | 自王の安全、駒の連携、相手の攻め筋を潰す |
| 🌀 策士 | 撹乱型 | 相手の選択肢を奪う、脅しを重ねる、読みにくい手 |
| 🏔️ 名将 | 大局型 | 駒の配置、ポーン構造、中央支配 |
| 💰 商人 | 実利型 | 駒得。堅実に取って堅実に守る |

同じ手を推す軍師はカードがまとまり、本命が重複した軍師は僅差の別案を出します。
相手 AI も同じ性格のいずれかで指し、指した手にひと言添えます。

## 構成

| ファイル | 内容 |
| --- | --- |
| `js/chess.js` | ルール実装 (0x88 盤、合法手生成、キャスリング、アンパッサン、昇格、千日手、Zobrist ハッシュ) |
| `js/eval.js` | 評価関数と性格定義 (駒価値、PST、機動力、王の安全、浮き駒、ポーン構造、中央、展開) |
| `js/search.js` | αβ探索 (反復深化、静止探索、置換表、キラー/ヒストリー、LMR) |
| `js/advisor.js` | 軍師の進言 (候補の絞り込み、手の特徴抽出、性格別セリフ) |
| `js/ui.js` | 盤面 UI と対局進行 |
